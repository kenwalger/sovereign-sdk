# Product Thesis

Modern AI systems are primarily designed around model capability.

Sovereign Systems is designed around computational boundaries.

Every system contains boundaries:

* Physical → Digital
* Untrusted → Trusted
* Local → Remote
* Memory → Storage
* Organization → External Provider

Most frameworks focus on what happens inside those boundaries.

Sovereign Systems focuses on governing the crossings between them.

The objective is not simply model orchestration.

The objective is trustworthy computation.

This philosophy produces a family of focused components:

| Boundary             | Component         |
| -------------------- | ----------------- |
| Physics → Digital    | sovereign-sensor  |
| Edge → Compute       | sovereign-edge    |
| Prompt → Structure   | sovereign-sieve   |
| Execution → Evidence | sovereign-ledger  |
| External → Sovereign | sovereign-airlock |
| Memory → Custody     | sovereign-vault   |

Every package exists to govern a single computational boundary.

If a proposed component cannot clearly identify the boundary it governs, it likely does not belong in the SDK.
